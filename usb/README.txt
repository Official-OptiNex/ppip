PPIP - Parts & PM  (USB / portable version)
===========================================

HOW TO USE
  Windows:  double-click  "Start PPIP (Windows).bat"
  Mac:      double-click  "Start PPIP (Mac).command"   (first time: right-click > Open)

Nothing is installed on the computer. The app opens in its own window
(Microsoft Edge or Chrome). Your sign-in is remembered on this USB stick.

SYNCING
  All data is stored online (the same database as the website), so this
  stick, the other sticks and every browser always show the same thing,
  live. If the PC has no internet, you can still look things up and make
  changes - they are saved on the stick and sent automatically as soon as
  the connection comes back.

FIRST TIME
  If you are asked for a "Server address", enter the website address
  (for example https://ppip.yourname.workers.dev).

Files:
  app\index.html     the whole app in one file (can also be opened directly)
  .browser-profile\  created on first run; stores your sign-in on the stick
